#1
Вывести все заказы Баранова Павла (id заказа, какие книги, по какой цене и в каком количестве он заказал) в отсортированном по номеру заказа и названиям книг виде.

Ответ:
SELECT buy.buy_id, book.title, book.price, buy_book.amount
FROM buy
JOIN client ON client.client_id = buy.client_id AND client.name_client LIKE 'Баранов Павел'
JOIN buy_book ON buy_book.buy_id = buy.buy_id
JOIN book ON book.book_id = buy_book.book_id
ORDER BY buy.buy_id ASC , book.title ASC

#2
Посчитать, сколько раз была заказана каждая книга, для книги вывести ее автора (нужно посчитать, в каком количестве заказов фигурирует каждая книга).  Вывести фамилию и инициалы автора, название книги, последний столбец назвать Количество. Результат отсортировать сначала  по фамилиям авторов, а потом по названиям книг.

Ответ:
SELECT author.name_author, book.title, COUNT(buy_book.amount) AS Количество
FROM author
JOIN book ON book.author_id = author.author_id
LEFT JOIN buy_book ON book.book_id = buy_book.book_id 
GROUP BY author.name_author, book.title
ORDER BY author.name_author ASC, book.title ASC

Интересное решение от пользователя с использованием COALESCE:
SELECT author.name_author, book.title, COUNT(buy_book.amount) AS Количество
FROM author
JOIN book ON book.author_id = author.author_id
LEFT JOIN buy_book ON book.book_id = buy_book.book_id 
GROUP BY author.name_author, book.title
ORDER BY author.name_author ASC, book.title ASC

#3
Вывести города, в которых живут клиенты, оформлявшие заказы в интернет-магазине. Указать количество заказов в каждый город, этот столбец назвать Количество. Информацию вывести по убыванию количества заказов, а затем в алфавитном порядке по названию городов.

Ответ:
SELECT city.name_city, COUNT(buy.buy_id) AS Количество
FROM city
JOIN client ON client.city_id = city.city_id
JOIN buy ON buy.client_id = client.client_id
GROUP BY city.name_city
ORDER BY city.name_city ASC, Количество DESC

#4
Вывести номера всех оплаченных заказов и даты, когда они были оплачены.

Ответ:
SELECT buy_step.buy_id, buy_step.date_step_end
FROM buy_step
JOIN step ON step.step_id = buy_step.step_id AND step.step_id = 1 AND buy_step.date_step_end IS NOT NULL

#5
Вывести информацию о каждом заказе: его номер, кто его сформировал (фамилия пользователя) и его стоимость (сумма произведений количества заказанных книг и их цены), в отсортированном по номеру заказа виде. Последний столбец назвать Стоимость.

Ответ:
SELECT buy.buy_id, client.name_client, SUM(buy_book.amount*book.price) AS Стоимость
FROM buy_book 
JOIN buy ON buy.buy_id = buy_book.buy_id
JOIN client ON client.client_id = buy.client_id
JOIN book ON book.book_id = buy_book.book_id
GROUP BY buy.buy_id, client.name_client
ORDER BY buy.buy_id

Ответ:
SELECT buy_step.buy_id, step.name_step
FROM step
JOIN buy_step ON buy_step.step_id = step.step_id
WHERE buy_step.date_step_end IS NULL AND buy_step.date_step_beg IS NOT NULL
ORDER BY buy_step.buy_id
