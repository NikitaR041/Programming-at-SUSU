#2
Случайным образом выбрать три вопроса (запрос) по дисциплине, тестирование по которой собирается проходить студент, занесенный в таблицу attempt последним, и добавить их в таблицу testing. id последней попытки получить как максимальное значение id из таблицы attempt.

Ответ:
/*шаг 4 - отсортированная таблица, по которой будем делать выборку*/
SELECT Q.question_id
FROM question Q
WHERE Q.subject_id = (
    SELECT subject_id
    FROM attempt
    WHERE attempt_id = (SELECT MAX(ATT.attempt_id) FROM attempt ATT)
    )
ORDER BY RAND()
LIMIT 3;

INSERT INTO testing (attempt_id, question_id, answer_id)
SELECT 
    (SELECT MAX(attempt_id) FROM attempt) AS attempt_id,
    question_id, 
    NULL -- Можно без этого, тогда не нужно третьего атрибута в первой строке этого запроса
FROM (
    SELECT question_id
    FROM question
    WHERE subject_id = (
        SELECT subject_id
        FROM attempt
        WHERE attempt_id = (SELECT MAX(attempt_id) FROM attempt)
    )
    ORDER BY RAND()
    LIMIT 3
) AS random_questions;

select * from testing;

#3
Студент прошел тестирование (то есть все его ответы занесены в таблицу testing), далее необходимо вычислить результат(запрос) и занести его в таблицу attempt для соответствующей попытки.  Результат попытки вычислить как количество правильных ответов, деленное на 3 (количество вопросов в каждой попытке) и умноженное на 100. Результат округлить до целого.

Будем считать, что мы знаем id попытки,  для которой вычисляется результат, в нашем случае это 8. В таблицу testing занесены следующие ответы пользователя:

+------------+------------+-------------+-----------+
| testing_id | attempt_id | question_id | answer_id |
+------------+------------+-------------+-----------+
| 22         | 8          | 7           | 19        |
| 23         | 8          | 6           | 17        |
| 24         | 8          | 8           | 22        |
+------------+------------+-------------+-----------+

Пояснение:
Используйте вложенный запрос для вычисления результатов всех попыток по таблице testing, а в таблице attempt обновляйте только запись с id равным 8.

Ответ:
UPDATE attempt
SET result = (
    SELECT ROUND(SUM(A.is_correct) / 3 * 100, 2)
    FROM testing T
    JOIN answer A ON A.answer_id = T.answer_id
    WHERE T.attempt_id = 8
)
WHERE attempt_id = 8;


SELECT * FROM attempt;

#5 - Задание на придумывание
/*
Вывести всех студентов, у которых результат меньше чем на 50 набранных баллов по всем учебным предметам (т.е. <50 набранных баллов).
Вывести на экран ФИО студента, предмет, вопрос, результат и ответ студента по этому вопросу.
*/
WITH my_table AS (
    SELECT SU.subject_id AS идишник, SU.name_subject, Q.name_question, A.name_answer
    FROM subject SU
    JOIN question Q ON Q.subject_id = SU.subject_id
    JOIN answer A ON A.question_id = Q.question_id
)
SELECT S.name_student, MT.name_subject, MT.name_question, MT.name_answer
FROM student S
JOIN attempt ATT ON ATT.student_id = S.student_id
JOIN my_table MT ON MT.идишник = ATT.subject_id
WHERE ATT.result < 50;
